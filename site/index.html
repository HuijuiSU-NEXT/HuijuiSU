安装

先确认内核类型，再选路线

适用于 GKI 2.0（5.10 / 5.15 / 6.1 / 6.6 / 6.12 / 6.18），不需要重编内核。

  1. 下载与内核 KMI 匹配的 kernelsu.ko
  2. 推送并加载：ksud insmod /data/local/tmp/xxx.ko
  3. 安装管理器 APK
  4. 打开 App，工具箱 → 一键隐藏
adb push aarch64-android16-6.12_kernelsu.ko /data/local/tmp/
adb shell su -c "ksud insmod /data/local/tmp/aarch64-android16-6.12_kernelsu.ko"
adb shell su -c "lsmod | grep -i ksu"

适用于 4.x / 非 GKI 魔改内核，需要重新编译 boot。

  1. 拉取设备对应内核源码
  2. 应用 KernelSU 补丁
  3. 编译并刷入 boot
  4. 安装管理器 APK
git clone --depth=1 <你的内核仓库> kernel && cd kernel
curl -LSs "https://raw.githubusercontent.com/HuijuiSU-NEXT/HuijuiSU/main/kernel/setup.sh" | bash -s main
# 用设备原本的编译脚本产出 boot.img 后
fastboot flash boot new-boot.img

常见问题

装完提示「未就位」？

v5.0.8 起已修复：改为 root 侧直接写入并校验，不再经过应用缓存复制。

元模块显示未检测到？

Hybrid Mount 装完需要重启一次才会生效；重启后状态会变成「元模块已生效」。

热刷入提示需重启？

只有纯 VFS 文件计划的模块能免重启，Magic / Overlay 后端仍需重启，这是 Hybrid Mount 的限制。

能卸载内置模块吗？

不能。内置核心模块禁止卸载与停用，避免隐藏链路失效。
