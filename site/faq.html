常见问题

按「现象 → 原因 → 处理」整理，遇到问题先扫一遍这里。

装了管理器，但所有功能都说没有 root

先看工具箱里的「Root 状态」卡片：

  • 出现 SU_UID=0 → root 正常，问题在具体命令
  • 提示无法执行 su → 管理器未被内核认可，需刷本项目内核或用本内核认可的管理器授权
一键隐藏提示「未就位」

v5.0.8 起已修复：改为 root 侧直接写入并校验，不再经过「应用缓存 → root 复制」这条会被 SELinux 拒绝的路径。

若仍出现，说明写入失败，卡片会显示真实错误（例如权限不足）。

元模块显示「未检测到」

Hybrid Mount 装完需要重启一次才会生效。重启后状态应变为「元模块已生效」。

若重启后仍提示未检测到，检查 /data/adb/modules/hybrid_mount/module.prop 是否存在。

热刷入提示需要重启

只有纯 VFS 文件计划的模块能免重启；Magic / Overlay 后端必须重启。这是 Hybrid Mount 的设计约束，不是管理器的限制。

能卸载或停用内置隐藏模块吗

不能。v5.0.10 起禁止卸载，v5.0.11 起同时禁止停用，避免隐藏链路失效导致检测不过甚至开机异常。

需要彻底移除只能通过命令行绕过管理器，但不建议。

版本号一直显示 v4.5.1-rc1

这是历史 bug：versionName 被硬编码。v5.0.3 起改为读取构建变量，之后版本号会正常显示。

软件包冲突装不上

先卸载同包名的旧版本；如果签名不同，系统会拒绝覆盖安装。

开机卡 logo

多半是 Zygisk 或 LSPosed 与内核不兼容。可尝试进入安全模式，或禁用对应模块后重启。
