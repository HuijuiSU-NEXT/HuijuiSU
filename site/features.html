功能详情

从内置资源到热刷入，从工具箱到稳定性，逐项说明它到底做了什么。

🛡

内置一键隐藏

隐藏模块随 APK 分发，不需要用户自己找包、导文件。首次启动自动部署到 /data/adb/huijui/，版本变化时自动覆盖。

  • 内置模块：Zygisk Next、LSPosed、HMA-OSS、OhMyKeymint、PIF-Dates
  • 自动导入 HMA 配置与 keybox
  • 自动生成黑白名单、写 denylist
  • 安装前清理旧版本，避免新旧并存
⚡

真·热刷入

接入内置元模块 Hybrid Mount 的运行时接口：

hybrid-mount runtime load <模块 id>
  • 纯 VFS 文件计划的模块：装完立即挂载，不用重启
  • Magic / Overlay 后端：会明确提示「需重启」，而不是含糊其辞
  • 元模块未就绪时，提示先装元模块并重启
🚀

开机秒激活

内置 huijui_core 模块，开机过程自动完成隐藏配置：

脚本时机做什么
post-fs-data.sh开机早期首次应用隐藏默认值（只跑一次）
boot-completed.sh开机完成自动安装元模块与隐藏模块

安装动作放在 boot-completed，避免拖慢开机。

🧰

稳定性与保护

  • 核心模块防误删：内置隐藏模块禁止卸载与停用
  • 崩溃日志：写入 cache/crash，含机型/系统/堆栈
  • root 侧文件判断：不再因为应用无权读 /data/adb 而误报
  • 安全失败：部署失败会带出真实错误，不吞异常
