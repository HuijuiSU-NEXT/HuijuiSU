安装

先确认内核类型，再选路线。选错是「装了却没有 root」的最常见原因。

适用

内核 5.10 / 5.15 / 6.1 / 6.6 / 6.12 / 6.18，能刷 boot 或 init_boot 的设备。不需要重编内核。

步骤

  1. 确认 KMI：uname -r，例如 6.12.69 对应 android16-6.12
  2. 下载对应 kernelsu.ko（aarch64 / x86_64）
  3. 推送并加载 ko
  4. 安装管理器 APK
  5. 打开 App → 工具箱 → 一键隐藏
# 以 6.12 的 arm64 设备为例
adb push aarch64-android16-6.12_kernelsu.ko /data/local/tmp/
adb shell su -c "ksud insmod /data/local/tmp/aarch64-android16-6.12_kernelsu.ko"
adb shell su -c "lsmod | grep -i ksu"
adb install HuiJuiSU_NEXT_Ultra_arm64-v8a-release.apk
已内置 KernelSU？ 如果 lsmod 里已经有 ksu，跳过第 3 步，直接装管理器，并在原管理器里授权它。

适用

4.x 内核、非 GKI 的 5.x 魔改内核。LKM 无法加载，只能把 KernelSU 编进内核。

步骤

  1. 准备设备内核源码与原始 boot.img（刷坏可回滚）
  2. 应用 KernelSU 补丁
  3. 用设备原本的编译脚本产出 boot
  4. fastboot 刷入
  5. 安装管理器 APK
git clone --depth=1 <你的内核仓库> -b <分支> kernel && cd kernel
curl -LSs "https://raw.githubusercontent.com/HuijuiSU-NEXT/HuijuiSU/main/kernel/setup.sh" | bash -s main

# 产出镜像后
fastboot flash boot new-boot.img
风险提示 刷 boot 有变砖风险，务必先备份原始 boot 分区，并确认能进 fastboot。
