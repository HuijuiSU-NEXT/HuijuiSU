## 一、首页电量：不再是假的 86%

### 问题

不管手机电量多少，首页永远显示 **86%** —— 因为那是写死的字符串。

### 修法

改成实时读取系统电量：

```kotlin
val bm = ctx.getSystemService(BATTERY_SERVICE) as BatteryManager
bm.getIntProperty(BATTERY_PROPERTY_CAPACITY)  // 0–100
```

读不到时显示 `--`，不再编一个数字。

## 二、超级用户：图标 + 默认只列用户应用

### 问题

反馈：「给超级用户权限那个功能全是系统应用，只有一个 123 网盘孤零零地在那」。

### 修法

| 项 | 处理 |
|---|---|
| **默认过滤** | 只显示用户应用（排除 `FLAG_SYSTEM` 且未更新的） |
| **手动切换** | 顶部开关「包含系统应用」 |
| **统计** | 副标题显示 `用户应用 N / 系统 M` |
| **图标** | 选择器每一行显示**真实应用图标**（取不到回退首字母） |
| **授权列表** | 同样显示真实图标 |

在测试机上验证：默认只列 3 个用户应用，打开开关后才出现 221 个系统应用。

## 三、Dock 拖动不再「怪」

### 问题

在 Dock 上按下时，指示器会**瞬间跳到手指位置**，看起来像故障。

### 修法

拖动起点改为「当前选中项的中心」：

```kotlin
onDragStarted = {
    dragPx = (selected + 0.5f) * (rowWidth / tabCount)
    dragFraction = selected.toFloat()
}
```

之后按手指位移累加，松手吸附到最近标签。拖动过程是连续的，不会先跳一下。

| 拖动前 | 拖动后 |
|---|---|
| 指示器停在首页 | 跟手滑动，松手落到目标标签 |

![Dock](https://cdn.jsdelivr.net/gh/HuijuiSU-NEXT/HuijuiSU@main/docs/images/v6.1.2/dock.png)

## 四、深浅色开关「像没反应」——现在能看出来

### 根因

壁纸模式下，文字早就统一成白色，卡片也早就切成深色玻璃。此时切「白色 / 黑色」，**画面上几乎没有差别**，所以像是没生效。

### 修法

让深/浅色直接体现在**玻璃浓度**上：

| 模式 | 顶部高光 | 黑色浓度 |
|---|---|---|
| 深色 | 24% | **30%** |
| 浅色 | 34% | **18%** |

切换后卡片厚薄、通透度都有明显变化，一眼能看出来。

## 五、依赖 ksud 的开关：说明白为什么没用

「内核设置」里的 5 个开关、以及「补丁中心」的 12 条补丁，全部通过 `ksud` 执行。

如果设备上 `ksud` 不在 PATH 或没有 root 权限，点了不会有任何反应——这很容易被当成「开关坏了」。

现在内核设置页会直接提示：

> **ksud 不可用**：这 5 个开关依赖内核接口，没有 ksud 或没有 root 时切换不会生效。
