## 一、壁纸：不再拉伸、不再模糊

### 问题

v6.1 的视频壁纸有两个硬伤：

1. **画面被强制拉长** —— 播放层写死了 `scaleX/scaleY = 1.26`，把画面硬拽变形
2. **非常模糊** —— 实际播放的是 360p 预览片（577 KB），不是原片

### 修法

**a. 用高清源**

| 之前 | 现在 |
|---|---|
| `miku_star_preview.mp4`（577 KB / 360p） | `miku_star.mp4`（5.9 MB / 高清） |

预览片只留作选择器缩略图。

**b. 反向补偿 TextureView 的默认拉伸**

`TextureView` 会把画面**非等比铺满**整个 View（天然拉伸）。正确做法是先求出 cover 比例，再换算成“相对默认拉伸的修正系数”：

```kotlin
scaleX = viewW / videoW
scaleY = viewH / videoH
cover  = max(scaleX, scaleY)

matrix.setScale(cover / scaleX, cover / scaleY, viewW/2, viewH/2)
```

结果：**等比、不裁错、不变形**。

**c. 静态图同样处理**

图片/GIF 一直是 `maxOf(w/iw, h/ih)` 等比 cover，这次与视频统一了行为。

## 二、点击闪黑 / 磨砂点不动 —— 换掉 SurfaceView

### 根因

壁纸原来用 `VideoView`，它内部是 **SurfaceView（独立图层）**。这个图层会：

- 盖在 Compose 内容上方 → **点击穿透失败**（磨砂卡片点不动）
- 按压重绘时露出空洞 → **闪一块黑**
- 叠加层拿不到视频帧 → 卡片看起来**发灰**

### 修法

换成 **TextureView + MediaPlayer**，视频在同一图层里渲染：

| 症状 | 结果 |
|---|---|
| 点击卡片闪黑 | ✅ 消失 |
| 磨砂卡片点不动 | ✅ 可点击 |
| 卡片发灰 | ✅ 恢复正常 |

另外壁纸**不再整体压暗**（`scrim = 0`），压暗只交给卡片自身的深色玻璃。

## 三、深色 / 壁纸下文字看不见

### 问题

设置里选「黑色」或开着动图时，文字仍是深色 → 黑底黑字。

### 修法

文字颜色改成**自适应**：

```kotlin
// 壁纸模式 或 深色主题 → 白字
val onDark = uiMode == Wallpaper || dark
```

| 场景 | 之前 | 现在 |
|---|---|---|
| 壁纸 + 浅色主题 | 深色字（看不清） | 白字 96% |
| 深色主题 | 深色字 | 白字 96% |
| 简约 + 浅色 | 深色字 | 深色字（不变） |

深色模式下卡片也统一走深色玻璃，不再出现“暗背景 + 白卡”的割裂。

## 四、Dock：支持拖动 + 液态玻璃

### 新增拖动

- 手指在 Dock 上左右拖，指示器**跟着手指走**
- 松手**吸附**到最近标签并切换
- 带轻微触感

### 指示器改液态玻璃

三层叠加：

1. 径向渐变**外发光**（液体边缘的反光）
2. 顶部白色**高光**
3. accent **描边**

配合 Dock 本体的深色玻璃（顶部 26% 高光 / 中部透壁纸 / 底边压暗），整条 Dock 是一块悬浮的液态玻璃。

### 问题

反馈：「给超级用户权限那个功能全是系统应用，只有一个 123 网盘孤零零地在那」。

### 修法

- 默认**只显示用户应用**（排除 `FLAG_SYSTEM` 且未更新过的）
- 顶部开关可切换「包含系统应用」
- 副标题显示统计：`用户应用 N / 系统 M`
- 列表显示**真实应用图标**（取不到时回退首字母）

## 六、修补 boot：不再卡住 / 不再没文件

### 问题

反馈：「修补文件的时候一些会卡住，一些修补好之后没有路径也没文件」。

### 修法

| 项 | 处理 |
|---|---|
| **卡住** | 命令加 `timeout 180`，超时自动结束 |
| **没文件** | 不看退出码，**直接校验产物是否存在**（`exists() && length > 1KB`） |
| **路径不明** | 输出改到 **`/storage/emulated/0/Download/`**，成功后打印完整路径与大小 |
| **识别失败** | 补丁前校验文件头必须是 `ANDROID!`；带 `--kmi` 用内核版本重试一次 |
| **失败原因** | 明确列出：内核非 gzip 压缩 / 镜像不匹配 / 4.x 需内核补丁 |
