# 真机验证清单（v6.0 / Nova）

模拟器无 root、无外网，以下两项**必须在真机验证**。其余项已在模拟器冒烟通过。

## 1. 在线模块仓库

| 步骤 | 预期 | 失败时看哪 |
|---|---|---|
| 模块页 → 右上「在线」 | 25 秒内出现列表，副标题 `N 个模块` | 若显示「网络超时」→ 设备无法直连 `raw.githubusercontent.com`，需要在 `ModuleRepo.kt` 里加镜像 |
| 搜索框输入 `zygisk` | 列表实时过滤 | 无结果说明索引里没有该关键词 |
| 点任意模块 | 出现「$ 下载 …」→「已下载，开始安装」→ 安装输出 | 下载失败看是否被墙；安装失败看 `ksud` 那行输出 |

镜像备选（若直连失败，把 `RAW` 常量换成其一）：

```
https://cdn.jsdelivr.net/gh/HuijuiSU-NEXT/Huijui_Module_Repo@main/modules.json
https://ghproxy.net/https://raw.githubusercontent.com/HuijuiSU-NEXT/Huijui_Module_Repo/main/modules.json
```

## 2. 超级用户「添加」授权（native ioctl）

| 步骤 | 预期 | 失败时看哪 |
|---|---|---|
| 超级用户 → 右上「添加」 | 出现应用列表（应等于手机已安装应用数） | 若为 0：检查 `QUERY_ALL_PACKAGES` 权限是否被系统限制 |
| 搜索并点「授权」 | 提示「已授权 xxx（重启后生效）」 | 提示 `code=-100` = 扫不到 `[ksu_driver]` fd（KernelSU 未加载 / 非 LKM）；`code=-1`=EPERM（SELinux 拦截）；`-22`=EINVAL（profile 字段不合法） |
| 重启后回到超级用户页 | 该应用出现在授权列表 | 不在 = 写入未落盘，属内核侧拒绝 |

返回码对照：`0` 成功；`-100` 无驱动 fd；`-101` so 未加载；`-102` 调用异常；其余为 `-errno`。
