## Что это

**Менеджер для форка KernelSU**, который не останавливается на «просто работает». Проблемы, с которыми реально сталкиваются root-пользователи, превращены во встроенные функции:

- **Не только предупреждает — исправляет**: проверка находит конфликты модулей, центр самовосстановления отключает их одним нажатием
- **Не заставляет копировать команды**: 12 встроенных патчей `resetprop`, применяются одним нажатием
- **Без фальшивых переключателей**: неподдерживаемые функции ядра показываются как «не поддерживается»

Интерфейс написан полностью с нуля и зависит только от Compose `foundation`.

---

## Четыре уникальные функции

| Функция | В двух словах | Почему у других такого нет |
|---|---|---|
| **Проверка одним нажатием** | 5 проверок + оценка 0–100 + прямые ссылки на исправление | Другие дают списки, а не выводы |
| **Центр самовосстановления** | Отключение конфликтующих модулей (обратимо) + очистка кеша | Другие только сообщают |
| **Центр патчей** | 12 патчей `resetprop`, откат при перезагрузке | Другие заставляют вводить команды |
| **Режим совместимости с 4.x** | Инструкции и патч boot для не-GKI ядер | Другие просто не поддерживают 4.x |

## Интерфейс

Четыре вкладки, тёмное стекло, динамические обои.

| Главная | Dock |
|---|---|
| ![Главная](docs/images/v6.1/home.png) | ![Dock](docs/images/v6.1/dock.png) |

- Тёмное стекло: блик 26% сверху, обои просвечивают в середине, низ затемнён
- Единый материал у карточек, дока и кнопок
- Обои масштабируются **с сохранением пропорций (cover)** — без растяжения, и для видео, и для фото
- Переключение китайского и английского (196 словарных пар, сохраняется)

## Возможности

- **Модули**: список, включение/отключение, удаление, установка из репозитория и из zip
- **Superuser**: список разрешений, отзыв (ioctl ядра), добавление по пакету, реальные иконки
- **Инструменты**: прошивка, обнаружение, скрытие, SUSFS, настройки ядра, терминал
- **Настройки**: режим UI, стекло, тема, акцент, обои, язык, о программе

## Установка

1. Скачайте APK под свою ABI из [Releases](https://github.com/HuijuiSU-NEXT/HuijuiSU/releases) (если не знаете — `universal`)
2. Установите поверх старой версии (`applicationId` не менялся, данные сохранятся)
3. При первом входе в «Модули» выдайте root

## Известные ограничения

- **Безопасный режим**: включается клавишей громкости при загрузке, у менеджера нет API записи
- **KPM**: в ядре этого форка нет загрузчика
- **Локализация**: интерфейс только на китайском и английском (README — на 6 языках)
- **4.x**: только инструкции и инструменты; сборка ядра требует исходников устройства
